# Alex Táxi Profissional 🚖

Website profissional para serviços de táxi executivo em São José do Rio Preto - SP.

## 🚀 Tecnologias

Este projeto foi desenvolvido utilizando as seguintes tecnologias modernas:

-   **[React](https://reactjs.org/)**: Biblioteca JavaScript para construção de interfaces.
-   **[Vite](https://vitejs.dev/)**: Ferramenta de build rápida e leve.
-   **[Tailwind CSS](https://tailwindcss.com/)**: Framework CSS utilitário para estilização rápida e responsiva.
-   **[TypeScript](https://www.typescriptlang.org/)**: JavaScript com tipagem estática para maior segurança.
-   **[Lucide React](https://lucide.dev/)**: Biblioteca de ícones leve e flexível.

## ✨ Funcionalidades

-   **Agendamento via WhatsApp**: Botões integrados com mensagens pré-preenchidas para facilitar o contato.
-   **Localização**: Mapa interativo (Google Maps) mostrando o ponto do táxi.
-   **Galeria de Fotos**: Exibição visual dos veículos e serviços.
-   **Design Responsivo**: Funciona perfeitamente em celulares, tablets e computadores.
-   **Links de Navegação**: Integração com Waze e Google Maps para rotas.

## 🛠️ Como rodar o projeto

Certifique-se de ter o [Node.js](https://nodejs.org/) instalado em sua máquina.

1.  **Clone o repositório:**

    ```bash
    git clone https://github.com/MarianaLebrao/alextaxi_projeto.git
    cd alextaxi_projeto
    ```

2.  **Instale as dependências:**

    ```bash
    npm install
    ```

3.  **Rode o servidor de desenvolvimento:**

    ```bash
    npm run dev
    ```

4.  **Acesse no navegador:**
    Abra `http://localhost:5173` para ver o site rodando.

## 📦 Build para Produção

Para gerar a versão otimizada para publicação:

```bash
npm run build
```

Para visualizar a versão de produção localmente:

```bash
npm run preview
```
